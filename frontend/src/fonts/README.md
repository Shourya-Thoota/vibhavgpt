# Google Sans

`GoogleSans-latin.woff2` and `GoogleSans-latin-ext.woff2` are Google Sans, a variable font (weights 400 to 700), as served by Google Fonts (`fonts.gstatic.com/s/googlesans/v76/`), self-hosted so the app makes no request to another site for its type.

Licence: SIL Open Font License 1.1, in `OFL.txt` (the copy from the `google/fonts` repository, `ofl/googlesans/`, whose `METADATA.pb` records `license: "OFL"` and the upstream `github.com/googlefonts/googlesans`). The licence permits use, embedding and redistribution, including in a commercial product, provided its notice travels with the font files, which is why `OFL.txt` is kept here. The font is not sold on its own and is not renamed.

Used for the chat interface (the sidebar and the chat screen). It is the closest properly licensed match to the typeface in the owner's reference screenshot, whose small text may be a related face (Google Sans Text) whose licence could not be established; that face is not used.
